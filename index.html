Загрузка данных

Загрузите новую выгрузку CSV из 1С и укажите коэффициент косвенных затрат. Можно просто перетащить CSV-файл в любое место окна — дата подставится из имени файла или сегодняшняя.

Файл должен быть сохранён из Excel в формате CSV (разделитель – точка с запятой).
Шапка: Номер;СуммаЗаказа;СуммаОплат;ОстатокОплат;ССПред;ССПлан;ССФакт;Дизайнер;Безнал

Легенда выделений

Объясняет цветовое выделение новых, удалённых и изменённых данных.

  • Новая строка
  • Удалённая строка
  • Изменённая ячейка
  • Нет плановой себестоимости
  • Отрицательное значение

Архив импортов

Список всех загрузок. Нажмите «Импорт от…» — откроются детали, подсветка и анализ.

    🤖 ИИ-анализ

    Три «субличности» — у каждой свой системный промт (открой «промт ▸», правь как хочешь, сохраняется автоматически). Данные готовятся локально и отправляются напрямую в Anthropic API.

    Ключ хранится только в этом браузере (localStorage) и уходит только на api.anthropic.com. Получить: console.anthropic.com → API Keys.
